# IPL Logo and Strategic Gap Note

The supplied IPL PNG is now the active header logo, browser favicon, and mobile home-screen icon. The PNG's transparent padding required a larger rendered box so the mark remains legible in the sticky header.

The most important missing element in the situation is **decision-to-action instrumentation**. The dashboard already shows a modeled value case, but it does not yet close the loop with live evidence and an operating workflow: a stable asset ID, exposure log, treatment/control assignment, consented outcome link, owner, approval state, and next action. Without that chain, the dashboard can recommend renewal but cannot prove which asset caused incremental commercial value or who is accountable for acting on the result.

The next product priority should therefore be a decision register tied to measured data, not additional visual polish: every asset should have an owner, evidence status, renewal recommendation, required proof, deadline, and approval outcome.
