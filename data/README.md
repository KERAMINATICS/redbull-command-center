# Dataset metadata

All quantitative values in this folder are **simulated assumptions** created for an independent portfolio case study. They do not represent actual Red Bull India performance and were not supplied or validated by Red Bull. The random seed is 42 so the data can be regenerated reproducibly. Monetary values are in Indian rupees.

Public context sources: Red Bull’s official company profile, Red Bull India careers/location page, and Red Bull’s official Athletes & Events support page. These sources are used for business context only.
